# 🍔 Burger Builder (V2 – Vite + TypeScript)

This is a modernized version of the original Burger Builder project.
The app was originally built with Create React App (CRA) and has now been migrated to Vite + TypeScript for faster builds, modern tooling, and better developer experience.
The previous version is archived in the /legacy folder.


🚀 Tech Stack

- React 19
- TypeScript 5
- Vite 7
- React Router 7
- Redux Toolkit 2
- Axios 1

---

🧩 Features

- Burger builder with dynamic ingredients and pricing

- Order form validation with TypeScript

- State management using Redux Toolkit

- Axios integration for backend communication

- Modular CSS with Vite support

⚙️ Installation

pnpm install
# or
npm install
# or
yarn install


💻 Development

pnpm dev
# or
npm run dev

🏗️ Build & Preview
pnpm build
